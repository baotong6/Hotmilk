## 🌌 About

**Hotmilk** is a shared research-computing environment for high-energy astrophysics data analysis.

It is mainly used for:

- 🛰️ XMM-Newton data analysis
- 🌠 X-ray source population studies
- 💫 Compact binaries and cataclysmic variables
- 📊 Multi-wavelength catalog cross-matching
- ⏱️ X-ray timing and spectral analysis
