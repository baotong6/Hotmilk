## 🌌 Hotmilk Project

The **Hotmilk project** aims at investigating the hot phase of the Milky Way, the so called Galactic corona.

For the scientific background, project overview, and recent studies, please visit the official project website:

## 🖥️ About This Repository

This GitHub repository focuses on the **Hotmilk server** and its research-computing environment.

It provides documentation for:

- 🛰️ XMM-Newton data analysis workflows
- 📁 Data storage and directory structure
- 🧰 Scientific software environments
- 📊 Catalogs and processed products
- ⏱️ Timing and spectral-analysis tools
- 🛠 Common server issues and troubleshooting
